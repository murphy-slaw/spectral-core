# Changelog for [Spectral Core](https://github.com/murphy-slaw/spectral_core)

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.4] 2026-03-16

### Added
- Removed built-in repair recipes from vc_gliders to allow them to be replaced with Tinkerer's Smithing

## [1.0.3]

### Added
- created a new block tag, `spectral-core:unspawanable`. Players will be prevented from spawning on these blocks. By 
  default it contains `minecraft:leaves`.

## [1.0.2]

### Changed
- Moved all of the dimension creation logic into the Suitcase mixin, removed Paintbrush mixin

## [1.0.1] 2026-2-27

### Changed
- Renamed to Spectral Core, since this is turning into a support mod for Spectral Seas
### Added

- Spectrum/Pocket Repose compatibility mixins.
  - Allows the Paintbrush to be used to bind the suitcase to a player-specific pocket dimension.

## [1.0.0] 2026-2-27

Initial public release.
